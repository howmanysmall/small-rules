## How releases work

`small-rules` uses [bumpp](https://github.com/antfu/bumpp) for versioning. Pushing a `v*.*.*` tag to the repository triggers a release.

Each release publishes to npm through Trusted Publishing (OIDC). `communique` writes the user-facing release notes, and `git-cliff` takes over if that generation fails.
