## Install

Add `small-rules` and `oxlint` to your roblox-ts project as dev dependencies:

<PackageManagerTabs />

## Configure

Register the plugin in `.oxlintrc.json`, then enable the rules you want to try:

```json
{
	"jsPlugins": ["@pobammer-ts/small-rules"],
	"rules": {
		"small-rules/no-print": "error",
		"small-rules/no-warn": "error",
		"small-rules/ban-react-fc": "error",
		"small-rules/no-task-wait": "error",
		"small-rules/prefer-early-return": "warn"
	}
}
```

<Aside type="note">
	I would start with a few rules, run them against the codebase, and add more once I know the noise level. `error`
	fails the lint check. `warn` reports a problem without failing it.
</Aside>

## Run

Run the linter:

```bash
oxlint .
```

If you want a package script, add one to `package.json`:

```json
{
	"scripts": {
		"lint": "oxlint"
	}
}
```

Then run:

<PackageManagerTabs preset="run" />

## Auto-fix

Some rules provide automatic fixes. Apply them with:

```bash
oxlint --fix
```

<Aside type="caution">
	Review auto-fixes before committing. They are intended to be safe, but code fixes can still meet an edge case.
</Aside>
