<RulePage rule="no-recursive">
	<Fragment slot="rationale">
		<p>
			This lint flags recursion. Luau has no{" "}
			<a href="https://github.com/luau-lang/luau/discussions/1183#discussioncomment-8719963">
				tail-call optimization
			</a>, which Roblox employees confirmed, so a recursive call can exhaust the stack. The National Aeronautics and
			Space Administration's{" "}
			<a href="http://web.eecs.umich.edu/~imarkov/10rules.pdf">Power of 10 rules for safety-critical code</a> also
			ban direct or indirect recursion so each path is deterministic and bounded. This suits code where
			performance and safety come first.
		</p>
	</Fragment>
</RulePage>
