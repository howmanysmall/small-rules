	<Fragment slot="rationale">
		<p>
			Ported from <a href="https://github.com/dmmulroy/anti-slop">dmmulroy/anti-slop</a>. An explicit `unknown`,
			`object`, open dictionary, or anonymous-object annotation can erase the useful evidence an object literal
			already has. Prefer inference, or `satisfies` when you need to check the object against a wider
			contract without throwing away its known keys.
		</p>
	</Fragment>
</RulePage>
