title: "Prefer `idiv`"
---

import RulePage from "$components/rule-page.astro";

<RulePage rule="prefer-idiv">
	<Fragment slot="rationale">
		<p>
			roblox-ts has `x.idiv(y)`. It does what `math.floor(x / y)` does, and it compiles to `x // y`. That skips a
			floor call. It should be a bit faster, and it says what you meant.
		</p>
		<p>
			Auto-fixes `math.floor(x / y)` to `x.idiv(y)`. It only reports when the right side is a division. It skips
			odd cases.
		</p>
	</Fragment>
</RulePage>
