---
title: "No Instance Methods Without `this`"
---

import RulePage from "$components/rule-page.astro";

<RulePage rule="no-instance-methods-without-this">
	<Fragment slot="rationale">
		<p>
			If a method never touches `this`, it shouldn't be a method. In roblox-ts, instance methods carry metatable
			overhead even when they don't use the instance. A standalone function is just faster.
		</p>
		<p>
			This catches any non-static method that never uses its own `this` or `super`. A `this` inside a nested
			`function`, object method, or class body belongs to that inner code, so it doesn't count. You can scope it
			with `checkPrivate`, `checkProtected`, and `checkPublic` if you only care about some visibility levels.
		</p>
		<p>
			Won't flag static methods or constructors. Those are fine. Only flags real instance methods that could be
			free functions.
		</p>
	</Fragment>
</RulePage>
