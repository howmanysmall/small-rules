---
title: "Require Module-Level Instantiation"
---

import RulePage from "$components/rule-page.astro";

<RulePage rule="require-module-level-instantiation">
	<Fragment slot="rationale">
		<p>
			Some classes should only ever exist once per file, and `Log` from `@rbxts/rbxts-sleitnick-log` is the one
			that matters: one logger per file, not a fresh instance every time a function runs. Let a class get
			instantiated inside a loop or a helper and you end up with a lot of them doing the same job.
		</p>
		<p>
			You tell the rule which classes matter through the `classes` option (class name mapped to its import
			source). You must create anything you configure at module scope, or it reports. That puts the expensive or
			stateful stuff exactly where it belongs.
		</p>
	</Fragment>
</RulePage>
