			filtering are absent, and it's useless in production.
		</p>
		<p>
			Use{" "}
			<a href="https://npmx.dev/package/@rbxts/rbxts-sleitnick-log">
				<code>Log</code>
			</a>{" "}
			instead. The API handles severity, not which global you called. Don't suppress this rule either.
		</p>
	</Fragment>
</RulePage>
