---
title: "Prefer Optional Parameter"
---

import RulePage from "$components/rule-page.astro";

<RulePage rule="prefer-optional-parameter">
	<Fragment slot="rationale">
		<p>
			`scenario?: ScenarioId` and `scenario: ScenarioId | undefined` accept the same values. The first one names
			the intent: the caller may omit the argument. The second one only allows undefined. It leaves the caller
			guessing whether to omit the argument or pass undefined.
		</p>
		<p>
			A default value and a rest parameter are already optional. The rule leaves them alone. The fix applies only
			where TypeScript allows the question mark. An optional parameter can't come before a required one. An
			accessor setter can't be optional at all. In those positions the rule reports the union. It doesn't rewrite
			it. A destructuring parameter can only be optional in a declaration signature, not in a function with a
			body.
		</p>
	</Fragment>
</RulePage>
