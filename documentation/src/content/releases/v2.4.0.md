# v2.4.0: Glob restrictions for property assignments

`no-restricted-property-assignment` now accepts glob patterns for both restricted object names and property names. The matcher also handles computed property names such as `_G[".secret"]` without applying filename-style basename matching to property values.

## 🚀 Added

- **no-restricted-property-assignment**: Match multiple objects or properties with glob patterns in `restrictions`, for example `{ object: "_G*", properties: ["__*__"] }`; literal property names continue to use exact matching - by @howmanysmall in [#12](https://github.com/howmanysmall/small-rules/pull/12)
