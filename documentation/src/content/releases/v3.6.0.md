# v3.6.0: Fewer reports from prefer-optional-parameter

This release narrows `prefer-optional-parameter`, the only rule with a behavior change. It stops reporting `undefined` unions in parameter positions where TypeScript does not allow `?`.

## 🔧 Changed
- **prefer-optional-parameter**: The rule no longer reports `undefined` unions on destructured parameters with a body, on parameters followed by a required parameter, or on accessor setters, including in `declare` and `abstract` classes. Previously `function getOpeningTurns(scenario: ScenarioId | undefined, count: number): void {}` reported without a fix. - by @howmanysmall in [#95](https://github.com/howmanysmall/small-rules/pull/95)
