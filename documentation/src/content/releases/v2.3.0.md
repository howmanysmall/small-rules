# v2.3.0: File-scoped exceptions for restricted assignments

`no-restricted-property-assignment` now supports file-scoped exceptions, so projects can keep the restriction enabled generally while permitting intentional writes in selected files.

## 🚀 Added

- **no-restricted-property-assignment**: Add the `allowFiles` option, an array of minimatch patterns that suppresses assignment and update diagnostics when the current filename matches. For example, `{ "allowFiles": ["*.story.{ts,tsx}"] }` exempts matching story files while non-matching files continue to report restricted writes - by @howmanysmall in [#11](https://github.com/howmanysmall/small-rules/pull/11)
