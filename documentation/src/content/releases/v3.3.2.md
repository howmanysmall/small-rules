# v3.3.2: Named function expression checks

`starts-with-verb` now checks names on named function expressions, so these functions receive the same naming diagnostic as other named functions.

## 🐞 Fixed
- **starts-with-verb**: `return function memoized() {}` now reports because `memoized` does not begin with a verb; this named function expression previously passed without a diagnostic - by @howmanysmall in [#82](https://github.com/howmanysmall/small-rules/pull/82)
