# v3.7.0: New require-readable-spacing rule for blank lines

This release adds the `require-readable-spacing` rule, which enforces blank lines between statements. No existing rule changes behavior, and the new rule runs only when you enable it.

## 🚀 Added
- **require-readable-spacing**: The rule requires blank lines after imports, between top-level statements, around declarations and multi-line bindings, before control flow, and after statements that end in a block. For example, `const a = 1;` followed by `foo(a);` reports, and the fix inserts the blank line. - by @howmanysmall in [#99](https://github.com/howmanysmall/small-rules/pull/99)

```json
"small-rules/require-readable-spacing": ["error", { "afterBlocks": false, "allowAttachedUses": true }]
```
