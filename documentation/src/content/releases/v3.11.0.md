# v3.11.0: New Cliffy rules for action handlers and command files

This release adds two Cliffy rules, `no-cliffy-action-wrapper` and `no-multiple-cliffy-commands`. No existing rule changed.

## Added
- **no-cliffy-action-wrapper**: The rule reports a Cliffy `.action` handler whose only statement passes its parameters to a named function, such as `.action((flags) => run(flags))`. Commands come from `new Command()` imported from `@cliffy/command` or from functions named in `factories`, which default to `["createBaseCommand"]`. - by @howmanysmall in [#113](https://github.com/howmanysmall/small-rules/pull/113)
- **no-multiple-cliffy-commands**: The rule reports every Cliffy command after the first in a file, including `new Command()`, `createBaseCommand(...)`, and inline `.command("list", "List things.")` subcommands. `.command("list", listCommand)` passes, because a non-string second argument registers a command defined elsewhere. - by @howmanysmall in [#113](https://github.com/howmanysmall/small-rules/pull/113)
