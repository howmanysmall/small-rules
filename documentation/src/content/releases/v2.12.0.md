# v2.12.0: Fewer false positives in loop and class rules

Version 2.12.0 is a focused bug-fix release for `no-dead-store`, `no-instance-methods-without-this`, and `require-async-suffix`. It removes false positives in loop analysis and class-member declarations without changing rule configuration.

## 🐞 Fixed

- **no-dead-store**: Treat compound assignments such as `count += 1` as reads of the previous value, and keep stores that are read across iterations of the same loop from being reported as dead - by @howmanysmall in [#32](https://github.com/howmanysmall/small-rules/pull/32)
- **no-instance-methods-without-this**: Skip TypeScript overload signatures and abstract method declarations, which have no implementation body to inspect, while continuing to report an implementation that does not use `this` - by @howmanysmall in [#33](https://github.com/howmanysmall/small-rules/pull/33)
- **require-async-suffix**: Skip async methods and arrow-function fields marked `override`, so members whose names are dictated by a base-class contract no longer require an `Async` suffix - by @howmanysmall in [#35](https://github.com/howmanysmall/small-rules/pull/35)
