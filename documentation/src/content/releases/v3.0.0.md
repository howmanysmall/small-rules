# v3.0.0: Sharper anti-slop boundaries

Version 3.0.0 updates several anti-slop rules to follow TypeScript aliases and wrapped types more precisely, avoids false positives for external API properties, and raises the minimum supported Node.js version.

## ⚠️ Breaking Changes

- **package-runtime**: Node.js 20 is no longer supported. Use Node.js `>=22.12.0` before upgrading - by @howmanysmall in [#60](https://github.com/howmanysmall/small-rules/pull/60)

## 🐞 Fixed

- **no-runtime-typeof**: Allows existence probes that compare `typeof` with the string literal `"undefined"`, such as `typeof document === "undefined"`, while continuing to report other runtime `typeof` checks - by @howmanysmall in [#60](https://github.com/howmanysmall/small-rules/pull/60)
- **no-shape-in-symbol-names**: Stops reporting non-computed external member properties, JSX member properties, and TypeScript qualified-name properties, so `nodePart.Shape`, `<Foo.Shape />`, and `type T = Foo.Shape` no longer report; local symbols such as `UserShape` still report - by @howmanysmall [<samp>(f5be6)</samp>](https://github.com/howmanysmall/small-rules/commit/f5be69ceb353cd2b648a1f282cca4677e14867fc)

## 🔧 Changed

- **no-known-value-widening**: Follows const aliases, type aliases, assertions, and local type-guard calls when deciding whether a known value flows into `unknown`, `object`, broad dictionary, or other anonymous contracts; for example, a known string passed to a local `value: unknown` type guard now reports - by @howmanysmall in [#60](https://github.com/howmanysmall/small-rules/pull/60)
- **no-object-parameters**: Resolves object-shaped contracts through aliases, parenthesized and union types, conditional type branches, and generic aliases, so parameters that hide the broad `object` type now report - by @howmanysmall in [#60](https://github.com/howmanysmall/small-rules/pull/60)
- **no-unknown-parameters**: Detects `unknown` inside unions and parenthesized types and across destructured, defaulted, rest, constructor, and function-type parameters, while preserving the exceptions for `cause` and the parameter validated by a type predicate - by @howmanysmall in [#60](https://github.com/howmanysmall/small-rules/pull/60)
- **no-unknown-returns**: Resolves unknown return contracts through aliases, generic aliases, unions, parentheses, and `Promise` or `PromiseLike` wrappers, so declarations such as `type Loader = () => Promise<unknown>` now report - by @howmanysmall in [#60](https://github.com/howmanysmall/small-rules/pull/60)
