# v2.10.0: Fewer false positives in component rules

Version 2.10.0 is a focused accuracy release for local component preference rules and `no-render-helper-functions`. It removes reports from component implementation files and recognizes render helpers passed through JSX attributes as valid callback references.

## 🐞 Fixed

- **prefer-context-stack**: Skip nested provider reports in files that define the local `ContextStack` component, so the implementation can continue to use its underlying providers directly - by @howmanysmall in [#27](https://github.com/howmanysmall/small-rules/pull/27)
- **prefer-local-portal-component**: Skip direct `createPortal` reports in files that define the local `Portal` component, so the component implementation is not required to replace its own portal factory call - by @howmanysmall in [#27](https://github.com/howmanysmall/small-rules/pull/27)
- **prefer-padding-components**: Skip matching `<uipadding />` reports in `EqualPadding` and `DirectionalPadding` definition files, while keeping the rule active for consumers of those components - by @howmanysmall in [#27](https://github.com/howmanysmall/small-rules/pull/27)
- **no-render-helper-functions**: Allow a render helper passed directly as a JSX attribute value, such as `renderItem={renderStoryItem}`, while continuing to report the same helper when used as a JSX child - by @howmanysmall in [#27](https://github.com/howmanysmall/small-rules/pull/27)
