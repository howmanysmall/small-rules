# v2.9.0: Eight new correctness and safety rules

v2.9.0 adds eight lint rules for correctness and code-quality checks. The new diagnostics cover unused assignments, unsafe floating-point comparisons and variadic spreads, isolated callback boundaries, mutation during iteration, trivial tests, inconsistent compound-word spelling, and use of values from void functions.

## 🚀 Added

- **no-dead-store**: Report local assignments whose values are never read, including stores overwritten before observation, while treating compound assignments such as `count += 1` as reads of the previous value - by @howmanysmall in [#24](https://github.com/howmanysmall/small-rules/pull/24)
- **no-floating-point-equality**: Report exact equality comparisons involving inexact floating-point values, including `==`, `===`, switch cases, equivalent bounded comparisons, and supported assertion APIs; exact decimal values remain allowed - by @howmanysmall in [#24](https://github.com/howmanysmall/small-rules/pull/24)
- **no-variadic-spread**: Report array spreads passed to `push`, `unshift`, `Math.max`, and `Math.min`, such as `target.push(...source)`; use iteration or a bounded array literal instead - by @howmanysmall in [#24](https://github.com/howmanysmall/small-rules/pull/24)
- **consistent-compound-words**: Report configured compound-word spellings in variable and function names, such as `passWord`, and suggest `password`; property checking and replacement maps are available through options - by @howmanysmall in [#25](https://github.com/howmanysmall/small-rules/pull/25)
- **isolated-functions**: Report outer-scope variables, `this`, and `super` used inside isolated callbacks and functions, including callbacks passed to `makeSynchronous`, `workerize`, `browser.execute`, and `page.evaluate`, plus functions marked with `@isolated` - by @howmanysmall in [#25](https://github.com/howmanysmall/small-rules/pull/25)
- **no-loop-iterable-mutation**: Report mutations to a live `for...of` iterable, such as `items.push(...)` while iterating `items`, while allowing snapshot loops and deletion of the current `Set` or `Map` item - by @howmanysmall in [#25](https://github.com/howmanysmall/small-rules/pull/25)
- **no-trivial-assertions**: Report assertions that always pass or fail, constant comparisons, and identity assertions against freshly created values such as `expect({}).toBe({})` - by @howmanysmall in [#25](https://github.com/howmanysmall/small-rules/pull/25)
- **no-use-of-empty-return-value**: Report using the result of functions that do not return a value, such as `const result = clear()`, while allowing calls used only for side effects and async or generator results - by @howmanysmall in [#25](https://github.com/howmanysmall/small-rules/pull/25)
