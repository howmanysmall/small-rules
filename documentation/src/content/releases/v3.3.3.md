# v3.3.3: Next-line suppressions for type assertions

`require-safety-comment-for-type-assertion` now recognizes a described `oxlint-disable-next-line` placed immediately before `as`, including when the directive is inside the asserted expression.

## 🐞 Fixed
- **require-safety-comment-for-type-assertion**: A described `oxlint-disable-next-line typescript/no-unsafe-type-assertion` immediately before `as` now counts as justification, so multi-line assertions such as `type({ ... // directive }).readonly() as Type` no longer report `missingSafetyComment` - by @howmanysmall in [#85](https://github.com/howmanysmall/small-rules/pull/85)
