# v2.5.0: Block async calls in synchronous systems

v2.5.0 adds one user-facing lint rule for Roblox-TS systems. `no-async-in-system` reports `Async`-suffixed calls made during synchronous Planck system execution, while leaving ordinary helpers and asynchronous system callbacks unchanged.

## 🚀 Added

- **no-async-in-system**: Report calls such as `service.commitAsync()` and `world.saveAsync()` from synchronous functions identified by the `PlanckSystem`, `System`, `SystemFunction`, `SystemReturn`, or `SystemTableLike` types. Add project-specific system return types with `{ "additionalSystemTypeNames": ["CustomSystem"] }` - by @howmanysmall in [#14](https://github.com/howmanysmall/small-rules/pull/14)
