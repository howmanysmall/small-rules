# v2.0.0: Consolidated expect assertion checks

The assertion rules are consolidated in `prefer-expect-assertions`, which now counts configured assertion helpers and autofixes deterministic `expect.hasAssertions()` calls. This release also removes the separate count rule and broadens the supported TypeScript peer dependency range.

## ⚠️ Breaking Changes

- **prefer-expect-assertions-count**: Remove this rule from your Oxlint configuration and enable **prefer-expect-assertions** instead; the consolidated rule includes its assertion-count checks and configuration - by @howmanysmall in [#5](https://github.com/howmanysmall/small-rules/pull/5)

## 🔧 Changed

- **prefer-expect-assertions**: Accept the new `additionalAssertionFunctions` option and count those function calls alongside built-in `expect` calls when validating assertion guards. For example, configure `{ "additionalAssertionFunctions": ["expectRecord"] }` to include `expectRecord(...)` in the count - by @howmanysmall in [#5](https://github.com/howmanysmall/small-rules/pull/5)
- **prefer-expect-assertions**: Report `expect.hasAssertions()` when a test has a deterministic positive assertion count, and autofix it to `expect.assertions(n)`; tests with loops, nested callbacks, or caught exceptions remain on `expect.hasAssertions()` because their counts are indeterminate - by @howmanysmall in [#5](https://github.com/howmanysmall/small-rules/pull/5)
- **package**: Expand the TypeScript peer dependency from `6` to `>=5 <8` - by @howmanysmall [<samp>(900a2)</samp>](https://github.com/howmanysmall/small-rules/commit/900a20f835e8adf230fbd8bc360320a2f3f0c9fd)
