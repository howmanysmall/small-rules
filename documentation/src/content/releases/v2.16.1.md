# v2.16.1: Broader anti-slop checks and JSX coverage

This release adds 15 anti-slop rules and expands static JSX hoisting detection. It also fixes type ownership resolution in `prevent-abbreviations` and prevents directive analysis from failing on comments without string values.

## ⚠️ Breaking Changes

- **no-reset-all-state-on-property-change**: The rule key changes from `no-reset-all-state-on-prop-change` to `no-reset-all-state-on-property-change`; update the rule name in your Oxlint configuration - by @howmanysmall <samp>(6b78c)</samp> in [6b78c](https://github.com/howmanysmall/small-rules/commit/6b78c7b264f15196571e1b14dc664c3b0cb168aa)

## 🚀 Added

- **no-chained-type-assertions**: Reports chains of multiple TypeScript assertions when at least one assertion is not `as const`, including parenthesized chains - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-conditional-empty-object-spread**: Reports object spreads such as `{ ...(enabled ? { value } : {}) }` that conditionally spread an empty object to omit properties - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-known-value-widening**: Reports known object, array, function, literal, and constructor values flowing into explicit `unknown`, `object`, open-dictionary, generic-container, or anonymous-object targets that discard their inferred evidence - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-module-mocking**: Reports Vitest and Jest module-mocking calls including `vi.mock`, `vi.doMock`, `vi.unstable_mockModule`, and their Jest equivalents - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-object-parameters**: Reports function parameters annotated as `object`, including aliases and unions that resolve to `object` - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-reflect-apply**: Reports calls to the global `Reflect.apply` - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-reflect-get**: Reports calls to the global `Reflect.get` - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-runtime-typeof**: Reports runtime `typeof` checks; the new `allowInTypeGuards` option defaults to `false` and can allow checks inside functions returning type predicates - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-shape-in-symbol-names**: Reports the case-insensitive substring `shape` in JavaScript, TypeScript, private, and JSX symbol names - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unknown-parameters**: Reports explicitly `unknown` function parameters except `cause` and the parameter validated by an explicit type predicate - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unknown-returns**: Reports functions whose explicit return type, including `Promise<unknown>` and aliases, exposes `unknown` to callers - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unknown-type-aliases**: Reports non-generic type aliases that resolve to `unknown` - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unsafe-dictionary-type**: Reports dictionary contracts whose values are `unknown`, `any`, `object`, `{}`, or aliases and unions containing those escape-hatch types - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-widen-then-assert**: Reports local `const` flows that first widen a known value and later assert the widened binding to a narrower type - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **require-safety-comment-for-type-assertion**: Reports TypeScript assertions without a nearby `SAFETY:` justification, while exempting `as const`; a described suppression for `typescript/no-unsafe-type-assertion` also counts as justification - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)

## 🐞 Fixed

- **prefer-hoisted-jsx-elements**: Reports static JSX found inside object properties and array elements when it is not already assigned to a module-level `const`, for example `const config = { icon: <Icon /> }` - by @howmanysmall in [#43](https://github.com/howmanysmall/small-rules/pull/43)
- **prevent-abbreviations**: Resolves property ownership through local type aliases, unions, intersections, indexed accesses, and interfaces that extend imported external types, so property names in external contracts are no longer treated as locally owned - by @howmanysmall in [#46](https://github.com/howmanysmall/small-rules/pull/46)
- **directive-require-description**: Safely ignores line comments whose parser value is not a string instead of attempting to trim or parse that value - by @howmanysmall in [#47](https://github.com/howmanysmall/small-rules/pull/47)
- **no-unsafe-dictionary-type**: Handles index signatures without a type annotation without crashing while continuing to report unsafe annotated dictionary values - by @howmanysmall <samp>(85c96)</samp> in [85c96](https://github.com/howmanysmall/small-rules/commit/85c96739600503ef67591f7fe9be61e2bcdbd9a7)

## 🔧 Changed

- **no-unknown-parameters**: Allows the parameter named by an explicit `value is T` or `asserts value is T` return predicate, because that parameter is the value being validated - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
