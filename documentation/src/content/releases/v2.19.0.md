# v2.19.0: Safer discovery and sharper Roblox checks

Version 2.19.0 updates test callback detection, makes local component discovery safer for generated and changing project trees, and refreshes Roblox API metadata used by default-value and yielding checks.

## 🐞 Fixed

- **prefer-expect-assertions**: Finds the test callback even when a numeric timeout follows it, so `it("works", () => { expect(value).toBe(1); }, 500)` now receives the expected assertion diagnostic instead of being skipped - by @howmanysmall [<samp>(43a6a)</samp>](https://github.com/howmanysmall/small-rules/commit/43a6a577784368a1225ff1d06c6415e4eeaafeb0)
- **prefer-context-stack**: Defers local component discovery until a provider chain is found, skips build output, `.gitignore` matches, and symbolic links, and treats unreadable or removed directories as empty instead of failing linting - by @howmanysmall in [#56](https://github.com/howmanysmall/small-rules/pull/56)
- **prefer-local-portal-component**: Defers local component discovery until a portal factory call is found and applies the safer project walk, so generated output is not indexed and transient directory errors do not abort linting - by @howmanysmall in [#56](https://github.com/howmanysmall/small-rules/pull/56)
- **prefer-padding-components**: Defers local component discovery until a padding element is found and applies the safer project walk, so generated output is not indexed and transient directory errors do not abort linting - by @howmanysmall in [#56](https://github.com/howmanysmall/small-rules/pull/56)

## 🔧 Changed

- **no-useless-default**: Uses refreshed Roblox instance defaults, so assignments and JSX properties matching newly supported defaults can now report, including defaults for `Accessory`, `Atmosphere`, `Clouds`, `InputActionLabel`, `TextChannelWindow`, and `ViewportCamera`; `PluginAction` and `RenderingTest` are no longer represented in the default table - by @howmanysmall [<samp>(db682)</samp>](https://github.com/howmanysmall/small-rules/commit/db68291f712511292e109e00b229880e4e4bc87f)
- **no-async-in-system**: Uses refreshed Roblox yielding-member metadata, changing which Roblox API member calls are recognized as yielding inside synchronous systems - by @howmanysmall [<samp>(4a635)</samp>](https://github.com/howmanysmall/small-rules/commit/4a6357ddb7e4b6cd4787066d57172a827d43dcf)
