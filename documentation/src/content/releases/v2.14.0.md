# v2.14.0: Reciprocal division and fewer false positives

Version 2.14.0 adds reciprocal-multiplication support to `prefer-idiv`, expands `require-named-effect-functions` for sloptor projects, and fixes false positives in `no-dead-store` and `prefer-pascal-case-enums`.

## 🚀 Added

- **prefer-idiv**: Report and autofix `math.floor` calls that multiply by an integer reciprocal, including `math.floor(x * 0.5)` to `x.idiv(2)`, `math.floor(0.25 * x)` to `x.idiv(4)`, and parenthesized or compound receivers such as `math.floor((a + b) * 0.5)` to `(a + b).idiv(2)` - by @howmanysmall in [#38](https://github.com/howmanysmall/small-rules/pull/38)
- **require-named-effect-functions**: Add the `sloptor` boolean option. With `{ environment: "roblox-ts", sloptor: true }`, named function expressions and references are handled using standard-mode behavior, while arrow and anonymous callbacks remain reported. Add the opt-in `inlineFunctionDeclarations` option for standard and sloptor modes, which autofixes `useEffect(doSomething, [])` to `useEffect(function doSomething() {}, [])` while preserving parameters and TypeScript annotations - by @howmanysmall in [#38](https://github.com/howmanysmall/small-rules/pull/38)

## 🐞 Fixed

- **no-dead-store**: Treat `return`, `throw`, `break`, and `continue` in an `if` consequent without an `else` as control-transfer paths, so stores that are overwritten on the reachable fall-through path are no longer reported as dead - by @howmanysmall in [#37](https://github.com/howmanysmall/small-rules/pull/37)
- **no-dead-store**: Keep a store live when a `switch` assigns a value in one arm and the value is read after the switch, including `switch (x.type) { case "arr": score = 1; break; default: score = 2; } return score;` - by @howmanysmall [<samp>(db5a3)</samp>](https://github.com/howmanysmall/small-rules/commit/db5a36cfc698b6b9fa4443287ab7bef06e9da0c3)
- **prefer-pascal-case-enums**: Skip enum declarations and members containing non-ASCII identifiers, such as `enum CommuniquéMode { Roblox, Studio }` and `enum Mode { Communiqué, Studio }`, instead of applying the ASCII-only casing check - by @howmanysmall [<samp>(ecd7b)</samp>](https://github.com/howmanysmall/small-rules/commit/ecd7bd9d7d134b9ce447061a493ccf6d2eeb1118)
