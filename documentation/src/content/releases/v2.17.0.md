# v2.17.0: Roblox syntax compatibility checks

Version 2.17.0 adds `no-unsupported-syntax` for Roblox projects and exposes `DependencyMode` from `no-useless-use-memo` at the package root.

## 🚀 Added

- **no-unsupported-syntax**: Reports `globalThis`, labeled statements, `.prototype` member access, regular-expression literals, and rest elements in array or object destructuring because roblox-ts cannot compile these forms to Luau. Each check is enabled by default and can be disabled independently, for example `{ spreadDestructuring: false }` when your toolchain supports rest destructuring - by @howmanysmall in [#51](https://github.com/howmanysmall/small-rules/pull/51)

## 🔧 Changed

- **no-useless-use-memo**: The package root now exports the `DependencyMode` type, so integrations can reuse its `"aggressive"`, `"empty-or-omitted"`, and `"non-updating"` option values - by @howmanysmall [<samp>(d82f9)</samp>](https://github.com/howmanysmall/small-rules/commit/d82f95edbf60645a53596a5118e1b119f6a24f82)
