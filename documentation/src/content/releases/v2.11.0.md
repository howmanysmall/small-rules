# v2.11.0: Fewer false positives in React and abbreviations

Version 2.11.0 is a focused accuracy release for `no-render-helper-functions` and `prevent-abbreviations`. It reports nested render helpers that were previously missed and avoids false positives for properties accessed through imported namespaces.

## 🐞 Fixed

- **no-render-helper-functions**: Inspect function expressions returned from another function, so a named helper such as `return function renderHelper() { return <div />; }` is reported; PascalCase components, hooks, and returned functions without JSX remain excluded - by @howmanysmall in [#31](https://github.com/howmanysmall/small-rules/pull/31)
- **prevent-abbreviations**: Resolve the outer imported identifier through nested member expressions and TypeScript qualified names, so `MenuPrimitive.Root.Props` no longer reports `Root` or `Props` as abbreviations when `MenuPrimitive` is an imported namespace - by @howmanysmall in [#31](https://github.com/howmanysmall/small-rules/pull/31)
