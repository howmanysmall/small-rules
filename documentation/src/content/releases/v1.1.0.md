# v1.1.0: New analysis rules and safer diagnostics

Version 1.1.0 adds a broad set of opt-in and recommended diagnostics for TypeScript, React, Roblox, and test code. It also changes several existing rule options and removes one standalone assertion-count rule, so review the breaking configuration change before upgrading.

## ⚠️ Breaking Changes

- **prefer-expect-assertions-count**: Remove this rule from your Oxlint configuration and use **prefer-expect-assertions**, which now includes assertion counting and the `additionalAssertionFunctions` option - by @howmanysmall [<samp>(ff6d7)</samp>](https://github.com/howmanysmall/small-rules/commit/ff6d751)

## 🚀 Added

- **consistent-compound-words**: Report inconsistent compound-word spellings such as `callBack`, `dataBase`, and `webHook`, with configurable replacements and variable/property coverage - by @howmanysmall [<samp>(83eab)</samp>](https://github.com/howmanysmall/small-rules/commit/83eab77)
- **isolated-functions**: Report references to outer-scope variables, `this`, and `super` inside functions marked by `@isolated`, configured function calls, browser/page evaluation callbacks, or selectors - by @howmanysmall [<samp>(83eab)</samp>](https://github.com/howmanysmall/small-rules/commit/83eab77)
- **no-loop-iterable-mutation**: Report mutations such as `items.push(...)`, `items.clear()`, and `items.sort()` while iterating the same iterable, while allowing mutations that remove the current item - by @howmanysmall [<samp>(83eab)</samp>](https://github.com/howmanysmall/small-rules/commit/83eab77)
- **no-trivial-assertions**: Report Jest and Node assertions that always pass or fail, including constant predicates and identity comparisons of freshly created values - by @howmanysmall [<samp>(83eab)</samp>](https://github.com/howmanysmall/small-rules/commit/83eab77)
- **no-use-of-empty-return-value**: Report using the return value of functions typed as returning `void` or an empty return type - by @howmanysmall [<samp>(83eab)</samp>](https://github.com/howmanysmall/small-rules/commit/83eab77)
- **no-array-constructor-index-assignment**: Report `new Array<T>()` followed by contiguous assignments such as `values[0] = first` and offer an array-literal fix - by @howmanysmall [<samp>(17ad2)</samp>](https://github.com/howmanysmall/small-rules/commit/17ad2aa)
- **no-recursive**: Report direct, mutual, async, generator, arrow-function, and class-method recursion at each recursive call site - by @howmanysmall [<samp>(db9bf)</samp>](https://github.com/howmanysmall/small-rules/commit/db9bf7f)
- **no-restricted-property-assignment**: Report assignments and updates to configured object properties, including wildcard and computed-property matches, with custom messages and file allowlists - by @howmanysmall [<samp>(8e345)</samp>](https://github.com/howmanysmall/small-rules/commit/8e3459c)
- **no-async-in-system**: Report calls to Async-suffixed functions from synchronous Planck system callbacks, including typed system objects and configured system type names - by @howmanysmall [<samp>(4cfe8)</samp>](https://github.com/howmanysmall/small-rules/commit/4cfe8fe)
- **no-filter-map-chain**: Report direct `filter(...).map(...)` chains that allocate an intermediate array; the rule is available but remains disabled by default - by @howmanysmall [<samp>(cd893)</samp>](https://github.com/howmanysmall/small-rules/commit/cd893c0)
- **no-dead-store**: Report variable writes that are never read, including dead stores across loop iterations - by @howmanysmall [<samp>(390c6)</samp>](https://github.com/howmanysmall/small-rules/commit/390c6ba)
- **no-floating-point-equality**: Report equality comparisons involving floating-point values where exact equality is unsafe - by @howmanysmall [<samp>(390c6)</samp>](https://github.com/howmanysmall/small-rules/commit/390c6ba)
- **no-variadic-spread**: Report spreading non-literal arrays into `push`, `unshift`, `Math.max`, or `Math.min`, such as `Math.max(...numbers)` - by @howmanysmall [<samp>(78a4e)</samp>](https://github.com/howmanysmall/small-rules/commit/78a4e7f)
- **prefer-direct-hook-imports**: Report namespace calls such as `React.useState(...)` and support standard React, roblox-ts React, and allowed-hook configurations - by @howmanysmall [<samp>(18cbe)</samp>](https://github.com/howmanysmall/small-rules/commit/18cbefe)

## 🐞 Fixed

- **use-exhaustive-dependencies**: Treat configured stable object properties as stable when destructured, including aliases, defaults, and quoted keys, so those values no longer appear as missing effect dependencies - by @howmanysmall [<samp>(70e3f)</samp>](https://github.com/howmanysmall/small-rules/commit/70e3f84)
- **enforce-ianitor-check-type**: Give root structural types a minimum depth score, so complex aliases, interfaces, and validator results are checked instead of receiving a zero depth multiplier - by @howmanysmall [<samp>(2e2f9)</samp>](https://github.com/howmanysmall/small-rules/commit/2e2f901)
- **prefer-hoisted-jsx-elements**: Treat self-referencing constants, unresolved calls, and accessor properties as dynamic instead of allowing them as static JSX values - by @howmanysmall [<samp>(e7434)</samp>](https://github.com/howmanysmall/small-rules/commit/e74342f)
- **directive-require-description**: Check line comments such as `// oxlint-disable-next-line no-console` and report them when they lack a `-- description` suffix - by @howmanysmall [<samp>(3cf8f)</samp>](https://github.com/howmanysmall/small-rules/commit/3cf8f16)
- **require-throw-error-capture**: Skip top-level throws and throws in anonymous callbacks that have no capture function, and avoid naming collisions with catch parameters - by @howmanysmall [<samp>(af46d)</samp>](https://github.com/howmanysmall/small-rules/commit/af46db8) [<samp>(a823f)</samp>](https://github.com/howmanysmall/small-rules/commit/a823f58)
- **no-dead-store**: Treat compound assignments such as `count += 1` as reads of the previous value and preserve stores read across loop iterations - by @howmanysmall [<samp>(abc6c)</samp>](https://github.com/howmanysmall/small-rules/commit/abc6c55)
- **no-instance-methods-without-this**: Skip TypeScript overload signatures and abstract methods without bodies while continuing to inspect implementations - by @howmanysmall [<samp>(c2a81)</samp>](https://github.com/howmanysmall/small-rules/commit/c2a8102)
- **require-async-suffix**: Skip async methods and fields marked `override`, and skip externally constrained object methods passed to calls such as `Bun.serve({ fetch() {} })` - by @howmanysmall [<samp>(6b6a2)</samp>](https://github.com/howmanysmall/small-rules/commit/6b6a26b) [<samp>(9ae3b)</samp>](https://github.com/howmanysmall/small-rules/commit/9ae3bfb)
- **prefer-pascal-case-enums**: Ignore enum names and members containing non-ASCII identifiers instead of applying the ASCII-only casing conversion - by @howmanysmall [<samp>(ecd7b)</samp>](https://github.com/howmanysmall/small-rules/commit/ecd7bd9)

## 🔧 Changed

- **require-throw-error-capture**: Add `allow` entries for error names, local file classes, global library classes, and imported package classes, with `path` filtering for file entries; use `library` instead of the earlier `lib` discriminator. Example: `{ allow: [{ from: "package", name: "ValidationError", package: "@cliffy/command" }] }` - by @howmanysmall [<samp>(af46d)</samp>](https://github.com/howmanysmall/small-rules/commit/af46db8) [<samp>(5c154)</samp>](https://github.com/howmanysmall/small-rules/commit/5c154dc)
- **no-commented-code**: Add `maxLines` to allow short commented-out code blocks, so `maxLines: 2` ignores groups of two or fewer lines - by @howmanysmall [<samp>(2ffd6)</samp>](https://github.com/howmanysmall/small-rules/commit/2ffd6d0)
- **prefer-expect-assertions**: Count configured assertion functions through `additionalAssertionFunctions` and autofix a deterministic `expect.hasAssertions()` guard to `expect.assertions(n)` - by @howmanysmall [<samp>(ff6d7)</samp>](https://github.com/howmanysmall/small-rules/commit/ff6d751)
- **require-async-suffix**: Add `except` to allow async identifiers whose names are dictated by an external API, such as `{ except: ["fetch"] }` - by @howmanysmall [<samp>(9ae3b)</samp>](https://github.com/howmanysmall/small-rules/commit/9ae3bfb)
- **no-restricted-property-assignment**: Support `allowFiles` glob patterns against relative paths as well as absolute filenames - by @howmanysmall [<samp>(cb835)</samp>](https://github.com/howmanysmall/small-rules/commit/cb83565)
