# v3.12.1: no-dead-store and require-paired-calls report more code

The `no-dead-store` and `require-paired-calls` rules now report code they previously missed.

## 🐞 Fixed
- **require-paired-calls**: The rule now reports an unpaired opener written with a unicode escape, such as `debug.profile\u0062egin("task");` with no closer. Previously that opener went unreported. - by @howmanysmall in [#118](https://github.com/howmanysmall/small-rules/pull/118)

## 🔧 Changed
- **no-dead-store**: The rule now reports a value that is overwritten before it is read in a block at module level, such as the initializer in `{ let attempt = first(); attempt = second(); publish(attempt); }`. Previously block scopes at module level were skipped. - by @howmanysmall in [#118](https://github.com/howmanysmall/small-rules/pull/118)
