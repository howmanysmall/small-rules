# v3.3.1: Verb-first naming, safer lint fixes, and an installable package

`starts-with-verb` adds a recommended naming diagnostic, fixes to `no-async-in-system`, `no-identity-map`, `prefer-single-world-query-in-jecs`, `prevent-abbreviations`, and `require-throw-error-capture` change which code reports or how fixes apply, and the plugin package installs correctly again for consumers outside the project workspace. v3.3.0 shipped with a broken package; this release carries its notes.

## 🚀 Added
- **starts-with-verb**: Reports function declarations, function-valued variables, and non-computed method or function-valued property names whose leading lowercase word is not recognized as a verb. For example, `userProfile()` reports and `getUserProfile()` passes; configure `allowList` and `denyList` to customize prefixes. Constructors, accessors, overrides, computed keys, and externally constrained object properties are left alone - by @howmanysmall in [#73](https://github.com/howmanysmall/small-rules/pull/73)

## 🐞 Fixed
- **package-installation**: The plugin bundle no longer declares the unpublished `@small-rules/oxlint-utilities` workspace package as a runtime dependency, so package installation no longer fails trying to resolve it - by @howmanysmall in [#79](https://github.com/howmanysmall/small-rules/pull/79)
- **no-async-in-system**: A quoted object key such as `"system"` now counts as a system property, so yielding Roblox API calls inside that function are reported - by @howmanysmall [<samp>(740a2)</samp>](https://github.com/howmanysmall/small-rules/commit/740a2b923f80320006a6d2f9e3430cd1c5658c91)
- **no-identity-map**: Chained identity calls such as `items.map(x => x).map(y => y)` now autofix to `items` in one pass - by @howmanysmall [<samp>(55850)</samp>](https://github.com/howmanysmall/small-rules/commit/55850db59971a70935c357a6025706ea551d3edb)
- **prefer-single-world-query-in-jecs**: Consecutive `world.get` calls now combine in groups of at most four components, so calls with five or more components do not produce an invalid oversized `get` call - by @howmanysmall [<samp>(b8f9b)</samp>](https://github.com/howmanysmall/small-rules/commit/b8f9b9ba16cc93c9e88f2731d8103adfd1fdfe5f)
- **prevent-abbreviations**: Autofixes no longer rename identifiers to `arguments`, `await`, or `eval`; if `arguments` is the only configured replacement, the fixer uses `arguments_` instead - by @howmanysmall [<samp>(63be6)</samp>](https://github.com/howmanysmall/small-rules/commit/63be6f53557b115be8f942ff2eb15e7d270e1f5f)
- **require-throw-error-capture**: Multiple fixes in the same block now use distinct local names, such as `error` and `error2`, instead of generating duplicate `const error` declarations - by @howmanysmall [<samp>(87209c)</samp>](https://github.com/howmanysmall/small-rules/commit/87209cf)
