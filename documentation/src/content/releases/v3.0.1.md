# v3.0.1: Fewer false positives in type guards

`no-known-value-widening` no longer reports known values passed to local type guards. Defensive checks such as `isString(properties)` now remain valid while direct widening into broad annotations continues to report.

## 🐞 Fixed

- **no-known-value-widening**: Stops reporting known arguments passed to local type-guard functions with an `unknown` parameter, including literals, aliases, assertions, typed return values, and function parameters; calls such as `isString('known')` and `isValid(properties)` no longer report - by @howmanysmall in [#61](https://github.com/howmanysmall/small-rules/pull/61)
