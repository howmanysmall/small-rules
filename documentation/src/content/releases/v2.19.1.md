# v2.19.1: Reliable package installation

Version 2.19.1 is a small packaging fix for consumers who could not install 2.19.0 because the unpublished private `@small-rules/arktype-utilities` package was listed as a runtime dependency.

## 🐞 Fixed

- **package-installation**: Bundles the private `@small-rules/arktype-utilities` package instead of publishing it as a runtime dependency, so installing the plugin no longer fails with `ERR_PNPM_FETCH_404` for that package - by @howmanysmall in [#58](https://github.com/howmanysmall/small-rules/pull/58)

**Full Changelog**: <https://github.com/howmanysmall/small-rules/compare/v2.19.0...v2.19.1>
