# v2.16.0: 15 anti-slop rules for TypeScript contracts

Version 2.16.0 adds 15 anti-slop rules for TypeScript contracts, assertions, reflection, tests, and naming. It also expands JSX hoisting detection, resolves external ownership through type aliases, and prevents malformed directive comments from crashing lint runs.

## 🚀 Added

- **no-chained-type-assertions**: Report chained `as` and angle-bracket assertions, including parenthesized chains, unless the chain consists only of `as const` assertions - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-conditional-empty-object-spread**: Report object spreads such as `{ ...(enabled ? options : {}) }` when one conditional branch is an empty object - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-known-value-widening**: Report known object, array, function, and literal values flowing into broad annotations such as `unknown`, `object`, `Record<string, unknown>`, or anonymous object types; use inference or `satisfies` instead - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-module-mocking**: Report Vitest and Jest module-mocking calls including `vi.mock()`, `vi.doMock()`, `vi.unstable_mockModule()`, and their Jest equivalents - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-object-parameters**: Report function and callable-signature parameters typed as `object`, including parameters whose type alias resolves to `object` - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-reflect-apply**: Report global `Reflect.apply()` calls and prefer a typed function call or named dispatch interface - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-reflect-get**: Report global `Reflect.get()` calls and prefer typed property access - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-runtime-typeof**: Report runtime `typeof` checks by default; set `{ allowInTypeGuards: true }` to allow them inside functions returning a type predicate - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-shape-in-symbol-names**: Report case-insensitive occurrences of `shape` in JavaScript, TypeScript, private, and JSX symbol names - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unknown-parameters**: Report explicitly `unknown` parameters, except a parameter named `cause` or the parameter validated by a type predicate - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unknown-returns**: Report function contracts that resolve to `unknown` or `Promise<unknown>`, including through non-generic type aliases - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unknown-type-aliases**: Report non-generic type aliases that resolve to `unknown`, including aliases through parenthesized types - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-unsafe-dictionary-type**: Report dictionary contracts whose values are `unknown`, `any`, `object`, `{}`, or unions and aliases containing those escape-hatch types - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **no-widen-then-assert**: Report local `const` values widened to `unknown`, `any`, `object`, or broad records and later asserted to a narrower type - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)
- **require-safety-comment-for-type-assertion**: Require a nearby `SAFETY:` justification for type assertions, except `as const`; a described `oxlint-disable-next-line typescript/no-unsafe-type-assertion` directive also satisfies the requirement - by @howmanysmall in [#44](https://github.com/howmanysmall/small-rules/pull/44)

## 🐞 Fixed

- **prefer-hoisted-jsx-elements**: Report JSX elements nested in object properties and array elements, such as `const config = { icon: <frame /> }`, when the initializer can be hoisted to module scope - by @howmanysmall in [#43](https://github.com/howmanysmall/small-rules/pull/43)
- **prevent-abbreviations**: Follow local type aliases, indexed access types, unions, intersections, and interface inheritance to determine whether an object type is externally owned, so properties from imported contracts are no longer reported as abbreviations - by @howmanysmall in [#46](https://github.com/howmanysmall/small-rules/pull/46)
- **directive-disable-enable-pair**: Handle directive comments with no string value without attempting to parse a missing value, preventing malformed comments from crashing lint runs - by @howmanysmall in [#47](https://github.com/howmanysmall/small-rules/pull/47)
