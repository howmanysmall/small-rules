# v2.18.0: Configurable type assertion bridges

Version 2.18.0 is a small rule-configuration release. `no-chained-type-assertions` now supports a narrow allowlist for nominal type bridges without changing its default diagnostics.

## 🔧 Changed

- **no-chained-type-assertions**: Add the `allowedTargets` option for identifier targets in a single `as unknown as T`, `as any as T`, or `as never as T` chain. For example, `{ allowedTargets: ["vector", "Vector3"] }` permits those bridges, while `as unknown as string`, unlisted targets, and longer assertion chains still report - by @howmanysmall in [#52](https://github.com/howmanysmall/small-rules/pull/52)
